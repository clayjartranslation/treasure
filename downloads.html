This Bible is free to read in the browser. There is nothing to buy, and there are no ads.

Keep it on an iPhone

  1. Open the site in Safari. Use the reader, not an in-app browser.
  2. Tap Share, then Add to Home Screen. The icon then opens like an app. The name on the icon is Treasure Bible.
  3. Open a book once while you are online. That copy stays on the phone, so you can read it later with no connection.

On other phones, use the browser menu and look for “Install app” or “Add to Home screen.” A computer can use the same site. After a book has loaded once, it can be read offline.

Your own notes

Bookmarks, highlights, and your place can be saved as a file you keep. Open Backup. That file is your notes. It is not a copy of the Bible text, and it is not uploaded by this site.
