## Chapter file format
- `paras: 1 3 6` lists the verses that start a paragraph
- `head N: Heading` puts a section heading at verse N (N must start a paragraph)
- `title: ...` is the chapter title, when there is one
- `N verse text{a}` is verse N; ` / ` marks a poetry line break; `{a}` marks a footnote
- `=a note text` is footnote a
- `# comment`

Follow `drafts/STYLE-GUIDE.md`. Use "Mortal one" for "son of man" (note at 2:1). Capitalize divine pronouns. Keep the names exactly as in the Clay Jar Translation.
